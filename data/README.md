# data/ — OCR リスト化の出力先

タウンページのページ画像から抽出した掲載店リストを、書籍ID・ページごとに CSV で保存します。

```
data/<BOOK_ID>/pageNNN.csv     例: data/202502_391646/page032.csv
```

`NNN` は **紙面に印刷されているページ番号**（3桁ゼロ埋め）です。

## CSV フォーマット

UTF-8、ヘッダー付き、列順は次の4列です。

| 列 | 内容 |
|----|------|
| カテゴリ | 紙面のオレンジ帯の業種見出し（例: アクセサリー、アパート・マンション） |
| 社名・店名 | 掲載名。親会社＋支店形式（エイブル㈱博多店 など）は結合して1行にする |
| 住所 | 【福岡市 博多区 (092)】等の地区見出しの市区町村を先頭に付けて結合。紙面の略記（「上川端」=上川端町 等）はそのまま |
| 電話番号 | 地区見出しの市外局番（092 / 0940）を付けて `092-XXX-XXXX` 形式。0120・0800 等はそのまま |

## 抽出ルール

- 広告枠（枠囲みの広告・「このページの広告をご覧ください」等）は無視する
- FAX 番号（Ⓕ）は収録しない。㈹（代表）マークは番号のみ残して除去
- 1事業者に複数番号がある場合は代表番号を採用
- 地区見出しをまたぐ支店一覧（「南,」「早,」等の区略号付き）は、略号の示す区の住所に展開する
- 住所欄が紙面にないもの（フリーダイヤルのみ等）は空欄

## 精度に関する注意

紙面は極小活字のため、**電話番号・番地は必ず原本と突き合わせて校正してください**。
特にチャット添付経由の画像は解像度が落ちるため誤読が混ざります。リポジトリの
`images/` に元解像度（el: 1448×2048）の JPEG を置いてから処理すると、画像を
分割拡大して読めるため精度が大きく上がります。
