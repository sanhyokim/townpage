# タウンページ1ページ分の抽出手順（読み取りエージェント用）

あなたの仕事は、タウンページのページ画像1枚から掲載店リストをCSV化することです。

## 入力

- タイル画像8枚: `<TILE_DIR>/el_<N>_c{1,2,3,4}{a,b}.png`
  - 紙面は本文4段組。`c1`〜`c4` が左から右の段、`a` が上半分・`b` が下半分。
  - 上下タイルは**120px重なっている**ので、境界付近の重複行は1回だけ収録すること。
- 元画像 `images/<EDITION>/el_<N>.jpg` は全体レイアウト（広告枠の位置、段の流れ）の確認用。
  読み取り自体は必ずタイルで行う（元画像は縮小されて誤読しやすい）。

## 紙面の構造

- オレンジ色の帯 = **カテゴリ（業種）見出し**（例: アクセサリー、アパート・マンション）
- 【福岡市 博多区 (092)】のような行 = **地区見出し**。以降の掲載の市区町村と市外局番を決める
- 掲載行 = 名称 ……… 電話番号 住所（住所は小さい字。ビル名階数が付くことがある）
- 記事は 1段目→2段目→3段目→4段目 の順に流れ、カテゴリ・地区見出しは段をまたいで有効
- 大きな枠囲みは**広告**。広告と「このページの広告をご覧ください」等の行は無視する
- ページ左上または右上の隅に**印刷ページ番号**がある

## 出力CSV

`data/<EDITION>/pageNNN.csv`（NNN = 印刷ページ番号3桁ゼロ埋め）に UTF-8 で書く。

```
カテゴリ,社名・店名,住所,電話番号
アクセサリー,モンベル福岡天神店,福岡市中央区天神2-4-38,092-718-2402
```

- 列は必ずこの4列。フィールドにカンマを含む場合のみ `"` で囲む
- 紙面の掲載順のまま出力する

## 抽出ルール

1. **カテゴリ**: 直近のオレンジ帯の業種名。ページ先頭がカテゴリ帯なしで始まる（前ページの続き）
   場合は `《承前》` と書く
2. **社名・店名**: 掲載名をそのまま。親会社名の下に支店がぶら下がる形
   （例: エイブル㈱ の下に 博多店）は「エイブル㈱博多店」のように結合して1行にする。
   「(○○のつづき)」とあれば○○を親名として結合する
3. **住所**: 地区見出しの市区町村を先頭に付ける
   - 福岡市の区 → `福岡市博多区` など
   - 宇美町・篠栗町・志免町・須恵町・新宮町・久山町・粕屋町 → `糟屋郡○○町`
   - その他の市 → 市名そのまま（春日市、大野城市、太宰府市、筑紫野市、那珂川市、古賀市、福津市、宗像市、糸島市 等）
   - 住所の前に区・市の略号（「南,」「早,」「博,」「筑紫野,」等）が付く行は、その略号の
     市区町村に読み替える（南=福岡市南区、早=福岡市早良区、西=福岡市西区、博=福岡市博多区、
     東=福岡市東区、中=福岡市中央区、城南=福岡市城南区 等）
   - 番地はハイフン区切りのまま。判読できない部分は無理に埋めず、読めた所まで書く
   - ページ先頭で地区見出しが不明（前ページの続き）の場合は住所先頭に `《承前》` を付ける
4. **電話番号**: 地区見出しの市外局番を付けて `092-XXX-XXXX` 形式
   - (0940) 地区は `0940-XX-XXXX`
   - フリーダイヤル（受話器マーク+0120/0800）や 0570・050 番号はそのまま
   - `(代)`・`㈹`・`[INS]` 等のマークは捨てて番号のみ
   - **Ⓕ（FAX番号）の行は収録しない**
   - 1掲載に複数番号がある場合は最初の（代表）番号のみ。ただし部署ごとに名前付きで
     並ぶ場合（例: 総務部/営業部）は「社名 部署名」で1行ずつ収録する
   - 市外局番不明（前ページの続き）の場合は `《承前》-XXX-XXXX`
5. 電話番号のない行（案内文など）は収録しない

## してはいけないこと

- 読めない文字を推測で創作しない（読めた部分＋残りは省略でよい）
- 広告枠の中の店を収録しない
- FAX番号・QRコード説明などを収録しない

## 最後に返すもの（最終テキスト）

CSVファイルを書き込んだ上で、次のJSONだけを返す:

```json
{"printed_page": 32, "file": "data/fukuoka/page032.csv", "rows": 213,
 "starts_with_carry": true,
 "last_category": "アパート・マンション",
 "last_municipality": "福岡市東区", "last_area_code": "092",
 "notes": "気付いた問題があれば簡潔に"}
```

`starts_with_carry` はページ先頭に《承前》を使ったかどうか。
`last_*` はページ末尾（4段目最後）時点で有効なカテゴリ・市区町村・市外局番。
